# Third-party notices

The plugin contains no third-party runtime libraries, music or fonts.

The traveler portraits under `plugin/assets/travelers/` are existing DANBO World project-owned character assets. The game-specific source, presentation, procedural field artwork and level rules are original project code.

`plugin/assets/audio/catch-success.wav` is an original AI-assisted sound generated specifically for this project with Stable Audio 3 Medium from a project-authored prompt, then trimmed and normalized locally. It intentionally excludes music, voices, coin sounds, retro arcade cues and imitation of existing game sounds. Generation provenance is documented beside the asset.

`plugin/assets/audio/obstacle-hit.wav` is an original AI-assisted sound generated specifically for this project with Stable Audio 3 Medium from a separate project-authored prompt, then trimmed and normalized locally. It intentionally excludes explosions, harsh crashes, metal or glass impacts, pain vocals, arcade injury cues and imitation of existing game sounds. Generation provenance is documented beside the asset.
